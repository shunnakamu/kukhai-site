Real-time intracardiac signal analysis for catheter ablation.

Electra, the model we are building, reads intracardiac electrograms and the surface ECG during the case. It runs under physician supervision, alongside the recording and mapping systems the lab already uses.

Talk to the team→

What Electra does

Three things the model is built to do, in the order the case runs.

  1. 1.0

    Read the whole recording

    Existing systems annotate points to build a map. Electra reads the recording along the time axis — intracardiac electrograms and the surface ECG together — so the case has a continuous record of what the signal was doing, not only the points that made it into the map.

  2. 2.0

    Estimate the signal where there is no catheter

    A catheter only records where it sits. From the surface ECG and the recorded channels, Electra aims to estimate the intracardiac signal where no catheter is — so a site can be evaluated without repositioning the catheter there.

  3. 3.0

    Assess the ablation endpoint

    Electra supports the call the operator makes at the end of each ablation application: is this lesion adequate, or does the line need another pass?

Working with existing systems

Electra is designed to run alongside the EP recording system and the 3D mapping system, reading the signals the lab already records and returning annotations, reconstructed channels, and an endpoint assessment. It does not replace either system.

Integration varies from lab to lab; the inputs are always signals the lab already records.

Electra is designed to be vendor-agnostic. We expect the main route to be licensing the algorithms to EP recording and 3D mapping system companies, rather than selling a separate box to hospitals.
